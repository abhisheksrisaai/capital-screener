# EVAL.md — Capital Screener answer-quality evaluation

Measures whether RAG answers stay grounded in the actual filings.
No invented numbers: the question bank is generated from `data/processed/`
artifacts, and every metric below is produced by runnable scripts.

## Quality bar (what counts as passing)

| Requirement | Bar |
|---|---|
| Factual/business answers | supported by a retrieved chunk, cited as `[Source: title, p.X]` |
| Numerical answers | value matches `financials.json`, cited page contains that value |
| Unanswerable questions | model says it is not found / unknown — never guesses |
| Citation precision (offline) | ≥ 0.50 on `evals/qa_set.jsonl` (CI gate) |
| Abstention contract | answering prompt requires "say so if unknown" (checked in CI) |

## Question bank — 40 items in `evals/qa_set.jsonl`

Generated by `evals/build_qa_set.py`, which only emits an item when its
anchor is verified present in (answerable) or absent from (unanswerable)
that company's ingested chunks. Regenerate after any refresh:

```bash
PYTHONPATH=backend python3 evals/build_qa_set.py
```

| Category | n | What it tests | Example |
|---|---|---|---|
| Factual | 10 | sector, scrip code, stated revenue | "Which sector is HPL Electric classified under?" |
| Numerical | 10 | exact table values (≥ Rs 20 cr, distinctive) | "What was Macpower's revenue in FY2024 (Rs crore)?" |
| Unanswerable | 10 | 5 out-of-range years + 5 topics absent from that company's chunks | "What was Dynemic's revenue in FY2027?" / promoter holding for a seed-profile company |
| Cross-year | 10 | FY-to-FY revenue change | "How did Tirupati's revenue change FY2025 → FY2026?" |

Known skew (honest limitation): 1260 chunks are concentrated in two long
real PDFs (Krishna Defence 732, Macpower 387); 14 companies have 8 seed-style
chunks each. Number questions can only be page-grounded where the value
appears verbatim, so numerical/cross-year items overweight those two
filings. Fix direction: ingest full PDFs per company instead of seed text.

## Rubric — grading a live answer

| Verdict | Rule |
|---|---|
| `grounded` | cites ≥ 1 expected page AND states the expected value |
| `abstained` | matches `not found / unknown / don't know / not disclosed` (correct only for unanswerable items) |
| `hallucinated` | everything else: wrong page, guessed value, or answered an unanswerable |

## Citation precision — method

`evals/eval_citation.py` runs each answerable item through the production
`RAGService.search` (TF-IDF + local Qdrant, reseeded from the committed
manifest when stale) and checks whether the pages the answer pipeline would
cite (top-4 sources, same window `answer_question` sees) intersect the
item's verified `expected_pages`. Page-level match, no partial credit.

```bash
PYTHONPATH=backend python3 evals/eval_citation.py           # offline, CI-safe
PYTHONPATH=backend python3 evals/eval_citation.py --live    # + real Groq grading (needs GROQ_API_KEY)
```

## Latest measured results (2026-09-13, offline, 30 answerable)

| Slice | Precise |
|---|---|
| Factual (10) | 10/10 |
| Numerical (10) | 2/10 |
| Cross-year (10) | 6/10 |
| **Overall citation precision** | **0.60** |
| Retrieval hit@5 | 0.60 |
| Abstention contract (10 unanswerable) | PASS |

Read of the misses: all 12 are number questions against the two long real
PDFs. TF-IDF ranks overview pages for "revenue + year" queries because the
target figure is not in the query text, so table pages never surface. Terms
present in the question (factuals) retrieve fine. Planned fix, not yet
implemented: route number questions to the SQL financials first, use RAG
only for narrative. The CI gate (≥ 0.50) locks current behavior so prompt
or chunking changes that regress this fail loudly instead of silently.
